# word-stream
Speed-reading web app: words stream past a fixed focus point so your eyes stay still. Opens PDF, EPUB, DOCX, TXT, HTML, Markdown or pasted text, and runs fully in the browser with nothing uploaded. Adjustable speed, sentence rollback, mouse-wheel word stepping, and saved reading progress.

you can use it on your own web browser with start.bat
